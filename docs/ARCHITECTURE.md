# Архітектура сцени

## Шар геометрії

Blender: приміщення, меблі, обладнання. Ретопологія знижує кількість полігонів, щоб сцена тримала FPS і проходила вимоги VRChat (менше заколисування).

## Шар матеріалів і світла

- PBR-текстури (Adobe Substance 3D Painter)
- Light baking у Unity — менше realtime-навантаження на GPU гравця
- Колізії на підлозі, столах, стінах

## Шар взаємодії

UdonSharp (C#): віртуальні екрани, тригери навчальних завдань, синхронізація стану обладнання між користувачами. Сцена залишена розширюваною під зовнішні модулі (AI, симулятори мереж, OSC).

## Інструменти

| Технологія | Призначення |
| --- | --- |
| Unity | Сцена, колізії, baking, збірка світу |
| VRChat SDK3 / Udon | Мережа, спавни, аудіозони |
| UdonSharp (C#) | Логіка терміналів і синхронізація |
| Blender | Моделі та оптимізація геометрії |
| Substance 3D Painter | PBR-текстури |

## Процес

Agile: паралельно моделювання, текстури, скрипти, збірка. Регулярні VR-прогони на FPS і мережу.
