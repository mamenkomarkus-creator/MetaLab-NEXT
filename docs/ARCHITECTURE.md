# Реалізація

**Геометрія.** Blender: зала, меблі, обладнання. Ретопологія тримає полігони в лімітах VRChat і береже FPS.

**Світло і матеріали.** PBR (Substance 3D Painter), light baking у Unity, колізії на підлозі, столах і стінах.

**Інтерактив.** UdonSharp: екрани, тригери, синхронізація стану між гравцями. Сцену можна розширювати модулями (AI, симулятори, OSC).

| Інструмент | Роль |
| --- | --- |
| Unity 2022.3.22f1 | Сцена, baking, збірка |
| VRChat SDK3 / Udon | Мережа, спавни, аудіозони |
| UdonSharp | Логіка й синхронізація |
| Blender | Моделі |
| Substance 3D Painter | PBR |

Agile: моделювання, текстури, скрипти й збірка паралельно. Регулярні VR-прогони.
