# Протокол вимірювань MetaLab

Документ описує, що виміряно, що ні, і як виміряти решту. Висновки подано в розділі 3.5 [`DOCUMENTATION.md`](../../presentation-materials/documentation/DOCUMENTATION.md).

## Стан вимірювань

| Показник | Стан | Де результат |
| --- | --- | --- |
| Склад сцени з репозиторію (об’єкти, колайдери, світло, lightmap-и) | виконано | [`scene-stats-2026-10-07.json`](scene-stats-2026-10-07.json), скрипт [`scripts/scene_stats.py`](../../scripts/scene_stats.py) |
| Версії Unity, SDK, VPM-пакетів | виконано | таблиця 2 документації |
| Режим кожної лампи (Realtime / Mixed / Baked) | **потрібна перевірка в Unity** | див. п. 1 |
| Трикутники, батчі, SetPass calls опублікованого світу | не виміряно | п. 2 |
| Розмір збірки після стиснення | не виміряно | п. 3 |
| Ретопологія до/після | не надано | п. 4 |

**Чому не виміряно.** Показники 2–5 потребують повного проєкту Unity (моделі, текстури й префаби, яких немає в репозиторії; `scene_stats.py` показує, що 4 префаби зі сцени в репозиторії відсутні), редактора або шолома. З YAML сцени їх отримати неможливо.

## 1. Режим освітлення

Для кожного з 6 джерел світла відкрити Inspector → **Light → Mode** і записати Realtime, Mixed або Baked. У збереженій сцені всі шість ламп мають однакове значення `m_Lightmapping: 4`; лише Inspector підтвердить, який це режим. Якщо будь-яка лампа в режимі Realtime, твердження про відсутність realtime-ламп у шоломі потрібно уточнити або лампи перевести в Baked і перепекти світло (**Window → Rendering → Lighting → Generate Lighting**).

## 2. Геометрія і виклики відображення

Відкрити сцену `MetaLab_Main`, у вікні **Game** увімкнути **Stats** у камері зі стартової точки появи і записати для трьох точок (точка появи, семінар, lounge): `Tris`, `Batches`, `SetPass calls`. Додатково: кількість унікальних матеріалів (**Window → Analysis → Project Auditor** або перелік у `Assets`).

## 3. Розмір збірки

Зібрати світ (**VRChat SDK → Build & Test** для PC) і записати розмір артефакту збірки після стиснення. Орієнтир для Quest — до 100 МБ [VRChat, *Quest Content Optimization*](https://creators.vrchat.com/platforms/android/quest-content-optimization).

## 4. Ретопологія «до / після»

Для 3–5 типових об’єктів (стілець, стіл, пуф, дошка) записати кількість трикутників до і після ретопології (Blender → **Statistics** в оверлеї вікна перегляду) і суму для всієї зали. Подати таблицею: об’єкт, до, після, зменшення, %.

## 5. Кадрова частота в шоломі

Інстанс на 1, 4 і 8 гравців (за можливості). У кожній із трьох точок по 2 хв записати середню частоту кадрів і 1 % low (SteamVR Frame Timing / Performance Graph або вбудований FPS VRChat). Вказати шолом, відеокарту, частоту оновлення і версію VRChat.
