## Як зайти

1. Встановіть VRChat (PC або PCVR): https://hello.vrchat.com/
2. Відкрийте посилання світу вище (потрібен обліковий запис VRChat).
3. Повний досвід — **PC / PCVR**. Quest — за можливості, після перевірки лімітів полігонів.

## Проєкт у репозиторії

Папка **`New Project/`** — світ Unity 2022.3.22f1.

1. Відкрийте VRChat Creator Companion і додайте цей проєкт.
2. Дочекайтеся відновлення пакетів VPM (`Packages/manifest.json` уже в Git).
3. Відкрийте сцену `New Project/Assets/Scenes/MetaLab_Main.unity`.
4. Інтерактив термінала: `Assets/Presentation/Interactables/TerminalInteractor.cs`.
